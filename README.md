# Sentinel AI · instaladores

Monitoramento de câmeras com inteligência artificial, processado no próprio computador. O vídeo não vai para a
internet e não há reconhecimento facial.

**Página de instalação e guia:** https://sentinel.wilsouza.com

Os arquivos ficam em [Releases](https://github.com/wilnarckson19-sys/sentinel-ai-instalador/releases):

| Arquivo | Sistema |
| --- | --- |
| `SentinelAI-2.2.0.pkg` | Mac com chip Apple (M1 ou mais novo), macOS 14 ou mais novo |
| `SentinelAI-Windows-2.2.0.zip` | Windows 10 ou 11, 64 bits (versão de testes) |
| `Guia-Sentinel-AI.pdf` | Guia de instalação, ativação e teste da câmera |

Este repositório guarda só os instaladores. Os componentes de código aberto incluídos (FFmpeg LGPL com o código-fonte,
Node.js, ONNX Runtime, modelos YOLOX) e as respectivas licenças acompanham cada instalador, na pasta de licenças.

Suporte: WilSouza.ai, WhatsApp https://wa.me/5595991673586

Cada instalação precisa de uma chave de ativação, presa ao computador, emitida pela WilSouza.ai.
